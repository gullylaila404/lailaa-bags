1. Executive Summary & Problem Definition

The goal of this assignment is to design, develop, and test an original, high-performance, frontend-only online store called LAILA BAGS. The project simulates a luxury fashion boutique selling handcrafted leather handbags, tote bags, crossbody bags, backpacks, and designer fashion accessories.

Per the assignment constraints:

  • Strictly Frontend-Only: Absolutely zero backend technologies (PHP, Node.js, Python, MongoDB, MySQL, Firebase, REST APIs) are deployed.
  • Technology Stack: Built using HTML5 for semantic structure, CSS3 for modern design tokens and responsiveness, and Vanilla JavaScript (ES6+) for dynamic logic.
  • Data Persistence: Implemented via the HTML5 Web Storage API (localStorage) for client-side persistence of shopping cart items, wishlists, coupon states, and placed orders.
  • Page Completeness: Exactly 11 distinct, fully linked HTML pages have been engineered with cohesive header navigation and footer components.
  • Currency Localization: All product pricing, subtotal calculations, and discounts are calibrated realistically in Pakistani Rupees (PKR / Rs.) with standardized numeric formatting.

4. Detailed Breakdown of the 11 Required Pages

Page 1: Home Page (index.html)

Serves as the primary brand showcase. Includes:

  • Announcement Bar: Displays complimentary express shipping on orders over Rs. 5,000 across Pakistan and promo code LAILA20.
  • Hero Banner: Large high-fashion banner containing "Elevate Your Everyday Style", descriptive copy, and dual CTAs: SHOP NOW (→ shop.html) and EXPLORE COLLECTION (→ categories.html).
  • Featured Categories: 6 responsive category cards (Handbags, Totes, Crossbody, Shoulder, Backpacks, Wallets) linking to filtered shop views.
  • Featured Products: 8 dynamically rendered luxury bag cards featuring high-res imagery, PKR prices, old price strikethroughs, badges, star ratings, and one-click cart additions.
  • Promotional Banner: Highlighting seasonal savings ("UP TO 30% OFF").
  • Why Choose Us: 4 trust pillars (Premium Quality, Fast Delivery, Secure Shopping, Easy Returns).
  • Customer Reviews: Verified testimonials with star ratings and reviewer avatars.
  • Newsletter Capture: Interactive subscription box triggering instant feedback toast.

Page 2: Shop Page (shop.html)

The comprehensive catalog listing page with dynamic filtering and sorting:

  • Search Filter: Live input querying product names, descriptions, and categories in real-time.
  • Category Sidebar: Quick-filtering across 9 categories with item counters.
  • Price Range Slider: Functional slider bound between Rs. 4,000 and Rs. 20,000.
  • Sorting Engine: Price Low-to-High, Price High-to-Low, Name A-Z, Name Z-A, and Highest Rated.
  • Refined Card Buttons: Responsive button architecture featuring a prominent Add to Cart button and a separate View Details arrow button, completely eliminating button text wrapping on all viewports.
  • Editorial Banner: Features high-resolution background imagery (shop-banner.jpg) with dark gradient overlay.

Page 3: Shop by Category (categories.html)

An editorial visual gallery presenting 8 distinct silhouettes (Handbags, Tote Bags, Crossbody Bags, Shoulder Bags, Backpacks, Wallets, Mini Bags, and Travel Duffels) with descriptions and direct shop links.

Page 4: About Us (about.html)

Presents the brand narrative, artisan Tuscan workshop heritage, mission, and vision. Features four live statistical milestone cards: 5,000+ Happy Customers, 100+ Artisan Products, 20+ Cities Delivered, and 4.8/5 Average Rating, alongside leather craftsmanship guidelines.

Page 5: News & Promotions (promotions.html)

Contains a real-time countdown timer tracking hours, minutes, and seconds for a seasonal flash sale. Features a one-click Copy Code (LAILA20) button and 6 distinct promotional campaign cards with read-more actions.

Page 6: Contact Us (contact.html)

Features client care contact details, showroom hours, WhatsApp concierge, and an interactive embedded Google Map of Fashion Avenue. The client message form incorporates strict JavaScript validation and triggers an animated confirmation modal upon valid submission without page reload. An interactive FAQ accordion clarifies return and shipping policies.

Page 7: Single Product Details (product.html)

Reads the query parameter ?id=X from the URL (defaulting gracefully to Product 1). Displays:

  • Main high-resolution image with interactive thumbnail gallery switcher.
  • Product name, star ratings, PKR price, old price, and discount badge.
  • Interactive color swatch buttons with active outline states.
  • Quantity stepper (+/-).
  • Actions: Add to Cart, Buy Now (adds item and redirects directly to checkout), and Wishlist toggle.
  • Tabbed panels for Specifications, Insured Pakistan Delivery, 30-Day Returns, and Customer Reviews.
  • Curated Pairings (Related Products) carousel.

Page 8: Wishlist (wishlist.html)

Reads saved products from localStorage. Allows users to view saved items, remove individual products, move items directly into the shopping cart, or clear the entire wishlist. Includes a dedicated empty-state screen when no items are saved.

Page 9: Shopping Cart (cart.html)

Complete interactive shopping cart:

  • Table view showing product thumbnail, chosen color, unit price, quantity steppers, and subtotals.
  • Dynamically calculates Subtotal, Shipping (Free over Rs. 5,000 or flat Rs. 250), Coupon Discount (20% off with LAILA20), and Grand Total.
  • Interactive delivery progress bar showing how much more to spend to unlock free delivery across Pakistan.
  • Direct transition to Checkout.

Page 10: Checkout (checkout.html)

Features multi-step input validation for Customer Information (First Name, Last Name, Email with regex check, Phone) and Shipping Address (Street, City, Province, Postal Code). Supports three frontend payment selectors:

  • Credit / Debit Card: Displays formatted 16-digit card input, expiration date (MM/YY), and CVV.
  • Cash on Delivery (COD): Displays instructions for doorstep cash payment.
  • Direct Bank Transfer: Displays bank account and IBAN information.

Submitting the form serializes the order into localStorage, clears the shopping cart, and redirects to thank-you.html.

Page 11: Thank You / Order Confirmation (thank-you.html)

Displays a celebration success checkmark, auto-generates a randomized unique Order ID (e.g., #LB-84920), displays order date, recipient name, address, payment method, items summary, and total amount in PKR. Includes a Print Receipt button utilizing native browser print styling.

5. Client-Side Data & LocalStorage Architecture

In place of a remote database, state persistence across pages is managed through four distinct LocalStorage keys:

Storage Key Data Type Schema / Contents
laila_cart_v1 Array of Objects [{ id, name, category, price, image, color, quantity }]
laila_wishlist_v1 Array of Numbers Array of saved product ID integers: [1, 3, 7]
laila_applied_promo String Active promotional code string: "LAILA20"
laila_last_order_v1 Object Serialized object containing order ID, date, customer info, and total items.
